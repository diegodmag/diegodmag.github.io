# Game Developer Portfolio — GitHub Pages

A responsive, minimalist portfolio starter built with plain HTML, CSS, and a small amount of JavaScript. No build tools or dependencies are required.

## Files

- `index.html` — all portfolio content and sections
- `style.css` — layout, colors, typography, and responsive styles
- `script.js` — mobile navigation and automatic footer year
- `assets/antique-shop-placeholder.svg` — replace with a screenshot from your game

## Customize before publishing

Search `index.html` for these placeholders and replace them:

- `Your Name` / `YOUR NAME`
- `YOUR.EMAIL@example.com`
- `YOUR-USERNAME`
- `href="#"` links for itch.io, gameplay video, Game Jam project, and LinkedIn
- `[Game Jam Project Name]`
- Project descriptions and skill lists

Replace the hero numbers and education details if they do not accurately describe you. Only publish professional project material you have permission to share. Never publish NDA-protected information.

## Preview locally

Open `index.html` in a browser. For a local development server, you can use the VS Code Live Server extension, but it is not required.

## Publish with GitHub Pages

1. Create a public GitHub repository named exactly `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root. `index.html` should be at the top level, not inside another nested folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait a few minutes and visit `https://YOUR-USERNAME.github.io/`.

For updates, edit the files and commit/push the changes to `main`.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
